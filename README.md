# Magneberry

GTK4-based music **and** audiobook library player for Linux, written in Rust.

Early planning phase. This repo holds the name; design work is happening in a
private workspace and will be published in stages.

## Intent

- One app, one local library, two ways to look at it: music and audiobooks.
- Built for large personal collections — fast scanning, reliable rescan, no
  files ever silently dropped.
- Music side: artist/album browsing, queue-first playback, gapless, playlists.
- Audiobook side: chapters, resume, bookmarks, sleep timer, adjustable speed.
- Clean libadwaita interface, keyboard-first, scriptable via CLI/MPRIS.
- Native performance: lean dependencies, small binary, fast start.

## Status

Planning. No source pushed yet. Milestones land branch by branch before any
public release.
